project iris prototype

Prototype for a now abandoned game project I had in 2025. It was gonna be a 2D action-platformer that took inspiration from games like Dust: An Elysian Tail, the Mega Man X series, and the beat-em-up genre of arcade games, mainly the DND Mystera series developed by Capcom. I had a lot of ideas and plans for it, but I guess that's what ultimately got me burnt out on developing it. Scope-creep sucks!

You can check it out on itch.io, along with it's source code on GitHub.

mm1 cutman stage

Demo of the Cut Man stage from Mega Man 1 that I was developing back in 2025 so that I could learn to use Godot. Because of the way I made it, it's real clunky and some things won't work properly, but I don't think it's too bad in my humble opinion.

If you wanna try it, it's on itch.io as a playable browser game and as a download.

Source code and files can be found at this repo.
